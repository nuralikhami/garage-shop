# Garage: переход на бесплатное облачное хранение

Подготовлено подключение к Supabase. Пока настройки не заданы, сайт читает локальную SQLite. Если задана только часть настроек Supabase, запуск останавливается вместо незаметного сохранения товаров во временную базу.

## 1. Подготовка Supabase

В SQL Editor выполните `supabase-setup.sql`. Он создаёт таблицу, включает RLS без публичных прав записи, добавляет `import_key` для повторяемого переноса и создаёт публичное хранилище `product-photos`.

## 2. Перенос существующих товаров

Создайте локальный `.env.local` по образцу `.env.example`. Укажите URL проекта и серверный Secret key Supabase. Файл исключён из Git. Ключ не отправляйте в чат, GitHub или код браузера.

В папке проекта выполните:

```powershell
node --env-file=.env.local migrate-to-supabase.js
```

Скрипт проверит все локальные фотографии, сохранит `migration-backup.json`, загрузит фото и перенесёт товары. Исходная SQLite не меняется. При повторном запуске импортированные товары пропускаются по `import_key`; запускать повторно после удаления импортированных товаров не нужно. В конце проверяются товары и доступность каждого фото. Если существующие товары были изменены через сайт, сначала нужно сохранить актуальную копию базы — локальный импорт берёт данные из `garage.db` на компьютере.

## 3. Настройки Render

В сервисе garage-shop → Environment задайте:

- `SUPABASE_URL`: URL вашего проекта Supabase.
- `SUPABASE_SECRET_KEY`: серверный Secret key, начинающийся с `sb_secret_`.
- `ADMIN_PASSWORD`: новый длинный пароль владельца. Старый пароль 12345 не используйте.

После переноса товаров и настройки окружения опубликуйте изменённый код. Секретные значения хранятся только в окружении сервера. Режим Supabase не пишет товары или фотографии на диск Render.

## 4. Проверка

Проверьте оба товара и фотографии, вход через ссылку «Вход для владельца», добавление тестового товара, редактирование без замены фото, замену фото и удаление. Затем перезапустите сервис Render и убедитесь, что изменения сохранились. После перезапуска вход в админку потребуется повторить.

Бесплатный Supabase может приостанавливать проект после недели неактивности. Автоматические резервные копии не включены в бесплатный тариф; сохраняйте отдельные копии важных товаров и фото. Локальная проверка `node --test cloud.test.js` использует имитацию облака; проверка реального проекта проводится после подключения.
